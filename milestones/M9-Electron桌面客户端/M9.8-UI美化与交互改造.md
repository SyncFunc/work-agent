# M9.8 桌面端 UI 美化与交互改造

> 范围：Electron 渲染层（`desktop/src/features/*`）的视觉与交互体验重构。
> 痛点来源：M9.0–M9.7 已实现全部功能，但样式几乎全部走组件内 `style={{...}}` 硬编码，**无设计 token、无暗色模式闭环、无图标体系、无加载/空/流式状态、模态缺焦点管理与 Esc、无 hover/动效反馈、面板不可伸缩**。功能可用，体验粗糙。
> 本文档同时作为改造方案的「实现方案 + 验收标准 + 知识沉淀」三要素载体（符合里程碑约定）。

---

## 1. 现状诊断（按严重度排序）

### 1.1 致命：无设计系统，暗色模式形同虚设

- `theme.css` 仅对 `body`/`aside`/`input` 等少数全局元素做了 `[data-theme="dark"]` 覆盖，但 **95% 的视觉来自组件 inline 样式里的硬编码十六进制色**（`#e7f0ff`、`#fdecea`、`#1a73e8`、`#fff` …）。
- 后果：切换暗色后，侧栏/聊天/弹窗仍是白底黑字硬色块——`applyTheme()` 改了 `<body data-theme>`，组件根本不读它。
- 证据：`App.tsx`、`MessageItem.tsx`、`ToolBlock.tsx`、`SubagentCard.tsx`、`ObsPanel.tsx`、`SessionList.tsx` 等全部 inline 设色。

### 1.2 严重：Emoji 充当图标，体验与可达性双输

- 顶栏 `📊`/`⚙`、工具块 `🔧`、后台 `🔄`/`✅`、计划 `📋`、关闭 `✕`/`×`。
- 问题：暗色下 emoji 自带彩色描边割裂主题；无统一视觉语言；屏幕阅读器读出「齿轮 emoji」而非语义；无法做描边/尺寸/状态变体。

### 1.3 严重：交互状态缺失

- **无 hover / active / focus-visible 态**：按钮、列表项、标签页只有 `cursor:pointer`，鼠标悬停无反馈，键盘聚焦无可见轮廓。
- **无 loading / skeleton / streaming 指示**：连接中显示纯灰字 `正在连接 daemon…`；回放时 `（回放中…）`；消息等待 `（等待输出…）`；工具 `运行中…` 只是彩色文字，无 spinner。
- **模态无焦点陷阱、无 Esc 关闭**：`AskModal`/`PlanModal`/`ApproveModal`/`SettingsPanel` 均无 Esc 与焦点环（仅 `CommandPalette` 实现了 Esc + 方向键 + 自动聚焦，是孤例）。
- **通知无自动消失、无类型样式**：`NoticeHost` 一律黑底白字（`error` 才红底），无倒计时、无操作按钮、无进出场动画、无最大堆叠限制。

### 1.4 中等：布局僵硬、无层级感

- 侧栏写死 `width:260`、可观测面板写死 `width:340`，**均不可拖拽伸缩、不可折叠**。
- 主区 `padding:16` 全局平铺，消息块之间仅靠 `margin:10px 0` 堆叠，无分组/分隔/时间线。
- 输入框 `footer` 无贴底视觉区分，无发送按钮主视觉、无快捷指令提示。
- 无 `min-width` 适配、无窗口极窄时的响应式降级。

### 1.5 中等：组件级视觉不一致

- 圆角混用 6/8/10；间距混用 4/6/8/10/12；字号混用 11/12/13/14/16；边框色 `#ddd`/`#eee`/`#e0e0e0` 三套并存。
- 同一「选中态」：会话列表用 `#e8f0fe` 底，标签页用 `#e8f0fe`+`#4285f4` 边框，obs tab 用 `#1a73e8` 下划线——同一语义三种表达。
- 状态色：`running` 在 StatusBar 用 `#1a73e8`、在 ToolBlock 用 `#b8860b`、在 SubagentCard 用 `#1a73e8`、后台用 `#1a73e8`——不统一。

### 1.6 轻微：内容渲染单薄

- `Markdown.tsx` 仅引入 `highlight.js/styles/github.css`——**只有亮色代码主题**，暗色下代码块刺眼；无代码块「复制」按钮、无行号。
- `DiffView.tsx` 仅行首着色，无行号 gutter、无 split 并排视图、无复制补丁按钮。
- 用户/助手消息无头像、无角色标签，仅靠底色区分。

## 2. 设计目标与原则

1. **单一事实来源的设计 token**：颜色/间距/圆角/字号/阴影/动效/层级全部收敛到 CSS 变量；组件只引用 token，不直接写 hex。
2. **暗色模式真正闭环**：所有颜色经 token；`[data-theme="dark"]` 切换变量即可全量换肤。
3. **语义化图标体系**：引入轻量图标库（`lucide-react`），替换全部 emoji。
4. **状态可见**：每个异步/等待处都有 loading / skeleton / streaming 指示；每个可点元素都有 hover / active / focus-visible。
5. **可达性达标**：所有模态支持 Esc + 焦点陷阱 + 自动聚焦；图标按钮带 `aria-label`；状态不只靠颜色（配图标/文字）。
6. **布局可塑**：侧栏与可观测面板可折叠、可拖拽伸缩；主区响应式。
7. **低侵入落地**：不推翻现有数据流（`useChatModel`/`useObs`/`useSessions` 等不变），只替换「样式层 + 少量交互壳」。

## 3. 设计方案

### 3.1 设计 Token 系统（新增 `desktop/src/renderer/tokens.css`）

  --wa-text-muted: #57606a;
  --wa-text-faint: #8b949e;
  --wa-primary: #1a73e8;
  --wa-primary-weak: #e8f0fe;
  --wa-success: #1e7e34;
  --wa-success-weak: #e6f4ea;
  --wa-warn: #b9770e;

- 替换 `theme.css`：仅保留 body 基础 + 把 `tokens.css` 引入；删除其中零散的 `aside/input` 覆盖（改由 token 表达）。
- **代码高亮主题同步**：`Markdown.tsx` 改按主题动态引入 `github.css` / `github-dark.css`（监听 `data-theme` 或读 `loadTheme()`）。

### 3.2 基础组件库（新增 `desktop/src/components/`，全部读 token）

抽离复用原语，消除 inline 重复：

| 组件 | 用途 | 关键点 |
|---|---|---|
| `Button` | 主/次/危险/幽灵 | variant + size；hover 加深、active 缩放、`focus-visible` 环；disabled 统一 0.5 透明度 |
| `IconButton` | 顶栏/关闭/刷新 | 必填 `aria-label`；固定 28×28 圆角 hover 底 |
| `Modal` | 所有弹窗壳 | **焦点陷阱 + Esc 关闭 + 点击遮罩关闭 + 进出场淡入缩放**；标题/主体/页脚插槽；`role="dialog" aria-modal` |
| `Badge`/`Pill` | 状态徽标 | `running`/`done`/`plan`/`exec` 用统一色 + 图标，不止颜色 |
| `Tabs` | obs / 设置分组 | 统一下划线/胶囊两种风格，键盘左右切换 |
| `Spinner` | 加载 | 统一尺寸/速度，替代「运行中…」文字 |
| `Skeleton` | 回放/首屏 | 骨架占位，替代灰字 |
| `Toast` | 通知 | 类型图标 + 自动消失 + 可选 action + 进/出场动画 + 最大 4 条堆叠 |
| `Tooltip` | 图标提示 | 替代裸 `title` |
| `Avatar` | 角色标识 | 助手/用户/子 agent 头像或字母徽标 |

- `hitl.css` 的 `.wa-modal` 逻辑迁进 `Modal` 组件，原直接写 `className="wa-modal"` 的组件（`AskModal`/`PlanModal`/`ApproveModal`/`SettingsPanel`/`CommandPalette`）改为包裹 `<Modal>`。

### 3.3 图标方案

- 引入 **`lucide-react`**（tree-shakeable、统一描边风格、仅 ~1KB/图标），替换全部 emoji：
  - 顶栏：`BarChart2`（可观测）、`Settings`（设置）
  - 工具块：`Wrench`
  - 后台：`Loader`/`CheckCircle2`；计划：`ClipboardList`；澄清：`HelpCircle`；错误：`AlertTriangle`
  - 关闭：`X`；fork：`GitBranch`；新建：`Plus`；刷新：`RefreshCw`
- 不引入整包 UI 库（MUI/AntD），保持轻量与现有 React+TS 技术栈一致、可控。

### 3.4 布局重构（`App.tsx`）

```
┌────────────┬───────────────────────────────┬────────────┐
│ 侧栏(可折叠)│ 主区                            │ 可观测(可折叠)│
│ 260↔折叠    │ Tab │ 会话头 │ 消息流(滚动)      │ 340↔折叠    │
│             │                                │            │
│             │ 贴底 composer（含快捷指令）      │            │
└────────────┴───────────────────────────────┴────────────┘
```
- 侧栏/obs 面板：增加**拖拽分隔条**（mouse drag 改 `width`，持久化到 localStorage）+ **折叠按钮**（折叠后变 32px 图标条）。
- 主区 `section` 改为独立滚动容器，composer 真正贴底并带顶部分隔线。
- 增加全局响应式：窗口 `< 900px` 时 obs 面板自动转抽屉（右侧滑出）。
- 顶栏标题 `Work Agent` 改为带 logo 占位 + 项目名；图标按钮统一 `IconButton`。

### 3.5 各模块改造细节

**聊天区 (`MessageList`/`MessageItem`)**
- 消息块加统一卡片底/分隔；助手消息左侧 `Avatar` + 角色名；用户消息右侧气泡（token 化 `--wa-bubble-user`）。
- 「思考过程」折叠改为带 `ChevronRight` 旋转的细按钮，思考区用 `--wa-surface-hover` 左侧条。
- streaming 中：`（等待输出…）` 改为闪烁光标/Skeleton 行；助手正在生成时头部加 `Spinner` + 「思考中」。
- 自动滚动：新消息贴底，但用户上滚时暂停（显示「↓ 回到底部」浮动按钮）。

**工具块 (`ToolBlock`)**
- 头栏加 `Wrench` 图标 + 统一状态 `Pill`（运行中=spinner+蓝、完成=绿勾、失败=红叉），去掉彩色文字。
- 参数/结果区用 `--wa-code-bg` + 行内 `复制` 按钮；超长截断阈值提升并提示更友好。
- 子 agent 块内默认折叠沿用，但折叠头显示「N 个工具调用」。

**子 agent 卡 (`SubagentCard`)**
- 顶栏 `subagent:{name}` 加 `Bot` 图标 + 状态 `Pill`（运行中 spinner / 已完成 绿勾）；可选进度（已完成步骤数，如 `3/7`）。
- 固定高度 220 改为**可拖拽/可折叠**整卡（折叠后只留顶栏），避免长会话刷屏。
- 主体内消息复用聊天区统一样式。

**可观测面板 (`ObsPanel`/`StatusBar`/`TraceTree`/`LogView`/`BackgroundAgents`)**
- 用 `Tabs` 组件统一 tab；关闭键改 `IconButton(X)`。
- `StatusBar`：token 进度条用 token 色 + 阈值色（>80% 红），模式 `Pill` 化。
- `LogView`：加日志级别过滤（INFO/WARN/ERROR）+ 单色行号 + 自动滚底。
- `BackgroundAgents`：任务卡用 `SubagentCard` 统一样式 + `刷新` 改 `IconButton(RefreshCw)`；正则里的 `🔄`/`✅` 字符串（来自 daemon 文案）建议后端改为中性文案，前端再映射图标。

**HITL 模态 (`Ask/Plan/Approve` + `Modal`)**
- 全部包裹 `<Modal>` → 自动获得 Esc/焦点陷阱/遮罩关闭/动画。
- `ApproveModal` 危险操作按钮用 `variant="danger"`；参数摘要加复制。
- `PlanModal` 步骤列表加状态图标（done=绿勾/failed=红叉/running=spinner），不再是纯文字 `[status]`。

**会话 (`SessionList`/`SessionTabs`)**
- 列表项 hover 高亮（`--wa-surface-hover`）、选中态统一 `--wa-primary-weak` 底 + `--wa-primary` 左条。
- `fork` 改 `IconButton(GitBranch)`，hover 才显形，避免常驻 clutter。
- 标签页加 `Tooltip`（全名）+ 关闭 `IconButton(X)`；支持 `Ctrl+1..9` 切换。

**设置面板 (`SettingsPanel`)**
- 用 `Modal` 壳 + 左侧分组 `Tabs`（LLM / 计划 / 安全 / 外观）；字段改为统一 `Field` 布局（标签上、输入占满）。
- 增加即时校验（api_key 非空提示、base_url 格式）；保存后 `Toast` 成功提示替代内联文字。
- 外观分组：主题切换即时预览（light/dark 单选卡）。

**命令面板 (`CommandPalette`)**
- 复用既有键盘逻辑；外表换 `Modal`/统一列表项 hover；图标 + 分组（slash 命令/动作）；支持最近使用。

**通知 (`NoticeHost` → `Toast`)**
- 类型图标（info/error/success）+ 自动消失（error 6s、info 4s）+ 可手动关 + 可选操作按钮 + 进出场滑入；最多堆叠 4 条。

### 3.6 内容渲染增强

- `Markdown.tsx`：动态主题高亮；代码块右上角「复制」浮动按钮（hover 显形）；表格/引用/列表统一间距。
- `DiffView.tsx`：左侧行号 gutter；顶部「复制补丁」按钮；可选并排（split）视图开关（大改用并排更可读）。

### 3.7 交互与可达性清单

- [ ] 所有模态：Esc 关闭 + 焦点陷阱 + 打开时聚焦首个可操作元素 + 关闭后焦点归位。
- [ ] 所有图标按钮：`aria-label`；所有状态：`图标 + 文字/形状` 双通道（不只颜色）。
- [ ] 全局快捷键文档化并在命令面板「快捷键」分组可见：`Cmd/Ctrl+K` 命令面板、`Cmd/Ctrl+B` 切换侧栏、`Cmd/Ctrl+J` 切换可观测、`Cmd/Ctrl+1..9` 切会话、`/` 聚焦输入框、`Esc` 关闭层。
- [ ] 按钮/列表/标签统一 hover/active/focus-visible；过渡 `var(--wa-dur)`。
- [ ] 加载态：连接中（`Spinner`+骨架）、回放中（`Skeleton` 列表）、工具运行（`Spinner`）。

## 5. 验收标准

- **暗色闭环**：设置切 dark，侧栏/聊天/全部弹窗/代码块无白底硬色块残留（`grep` 全仓确保组件无残留硬编码品牌 hex，仅 token 变量）。
- **零 emoji**：全仓 `desktop/src` 不含 `🔧📊⚙📋✕×🔄✅💡` 等作为 UI 图标（daemon 下发的通知文案除外，但前端映射为图标）。
- **模态一致**：任意弹窗按 Esc 关闭、Tab 焦点不逃出、打开自动聚焦——用一次手工走查 + 关键组件快照测试。
- **状态可见**：连接中/回放中/工具运行中均有非纯文字的视觉指示（spinner/skeleton）。
- **布局可塑**：侧栏与 obs 面板可折叠、可拖拽改宽并持久化；窗口 < 900px 时 obs 自动转抽屉。
- **CI 不退化**：`npm run lint`(tsc) 与 `vitest` 全绿；不引入 MUI/AntD 等重依赖（仅 `lucide-react`）。
- **无回归**：现有数据流与事件映射逻辑不变，仅样式/交互壳替换。

## 6. 风险与取舍

- **依赖引入**：仅新增 `lucide-react`（轻量、tree-shake）。**不引入**完整组件库，避免与现有 React+TS 架构耦合、包体膨胀、风格不可控。
- **是否 Tailwind**：本方案选「CSS 变量 + 自建原语组件」，理由：① 现有 `hitl.css`/`theme.css` 已是普通 CSS，迁移成本最低；② 不引入构建链与类名心智负担；③ token 用 CSS 变量天然支持暗色。如团队偏好原子化，可改 Tailwind（`darkMode:'class'` + `theme.extend` 引用同一变量），但属更大改动，建议二期。
- **暗色数据来源**：daemon 下发的通知/状态文案仍可能带 emoji（如 `🔄 运行中`），属后端文案，不在本改造范围；前端对已知模式做图标映射，新文案默认中性。
- **性能**：CSS 变量切换零重渲染；`Modal`/`Toast` 为轻量组件，无虚拟列表需求（消息流已是增量渲染）。

## 7. 知识沉淀

- **唯一真相**：所有颜色/间距/圆角/字号/阴影/动效收敛到 `tokens.css` 的 CSS 变量；组件禁止写死 hex，暗色只切变量。
- **图标**：统一 `lucide-react`，禁 emoji；图标按钮必须 `aria-label`。
- **模态契约**：所有弹窗必须经 `<Modal>` 壳，自动获得 Esc + 焦点陷阱 + 遮罩关闭 + 动画，不要各自写 `.wa-modal`。
- **状态双通道**：状态不只靠颜色，配图标/文字，保证色盲可达。
- **布局可塑**：侧栏/obs 宽度用 state + localStorage 持久化，不写死；窗口窄时 obs 转抽屉。
- **验收红线**：改完后全仓不得残留 emoji 作图标、不得残留硬编码品牌色；`tsc`/`vitest` 全绿、不引入重 UI 库。
