# Step M10.1 后端事件模型与 message_id 打标

## 实现方案

- 目标：把「一次响应」建模为 `message`，给 `Event` 增加 `message_id` / `parent_message_id`；新增 `EventType.USAGE`；`EventStream` 提供**唯一打标漏斗**，使 `step` 期间所有 event 自动带上当前 `message_id`，调用方无需逐条传参。

- 改动文件：
  - `agent/core/events.py`
  - `agent/core/session.py`

- 关键接口/算法（伪代码 / 签名）：

  **1. `EventType` 增加 USAGE（`events.py`）**
  ```python
  class EventType(StrEnum):
      ...
      USER = "user"
      USAGE = "usage"  # 新增：每 message 的用量/耗时事件（落盘 + 可回放）
  ```

  **2. `Event` dataclass 增加字段（`events.py`）**
  ```python
  @dataclass
  class Event:
      type: EventType
      transient: bool = False
      ts: float = 0.0
      message_id: str | None = None  # 新增：归属的 message
      parent_message_id: str | None = None  # 新增：子 agent 指向直接父 message
      ...  # 既有字段不变
  ```
  `to_dict()` / `from_dict()` 同步增 `message_id` / `parent_message_id` 两键。

  **3. `EventStream` 唯一打标漏斗（`events.py`）**
  ```python
  class EventStream:
      def __init__(self, maxlen=None):
          ...
          self.current_message_id: str | None = None
          self.current_parent_message_id: str | None = None

      def append(self, ev: Event) -> Event:
          ev.seq = self._seq
          self._seq += 1
          if ev.ts == 0.0:
              ev.ts = time.time()
          # 唯一打标点：未显式标注的事件自动继承当前 message 上下文
          if ev.message_id is None:
              ev.message_id = self.current_message_id
          if ev.parent_message_id is None:
              ev.parent_message_id = self.current_parent_message_id
          self._events.append(ev)
          ...
  ```
  > 这是全局唯一的打标点；`loop.py` 内部 `append` 均不再手动传 `message_id`，避免漂移。

  **4. `session.py` 生成 / 透传 `message_id`**
  ```python
  # step() 接收或生成 message_id，调用 loop 前设置到 stream
  def step(self, task, *, message_id=None, parent_message_id=None):
      message_id = message_id or uuid4().hex
      self.event_stream.current_message_id = message_id
      self.event_stream.current_parent_message_id = parent_message_id
      res = self.loop.run(...)  # 期间所有 append 自动带 message_id
      return dataclasses.replace(res, message_id=message_id)  # 见下
  ```
  `AgentResult` 增加 `message_id: str | None = None` 字段。

- 依赖 / 环境：无新依赖；sqlite 存 `ev.to_dict()` 的 JSON，新字段自动兼容，无需 migration。
